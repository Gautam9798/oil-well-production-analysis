# Oil Well Production & Performance Analysis

## Overview

A data analytics project analyzing oil-well production performance using MySQL and Excel.

The project evaluates oil production, water cut, decline rate, and overall well performance to identify high-performing wells and wells requiring attention.

## Tools Used

- MySQL
- SQL
- Microsoft Excel

## Analysis Performed

- Total oil production analysis
- Production by field
- Top producing wells
- Water cut analysis
- Production decline analysis
- Active vs inactive wells
- Well performance classification
- Identification of wells requiring attention

## Well Performance Classification

Wells are classified into:

- Strong
- Moderate
- Needs Attention

The classification is based on production performance, water cut, and decline rate.

## Excel Dashboard

The final Excel dashboard summarizes the analysis through:

- Total Oil Production
- Average Water Cut
- Average Decline
- Active Wells
- Wells Needing Attention
- Production by Field
- Performance Distribution
- Top Producing Wells
- Water Cut vs Oil Production
